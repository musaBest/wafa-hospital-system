Wafaa Hospital System v4.3.81

تحديث قسم المسنين والمسنات:
- إضافة واجهة مستقلة للمسنين والمسنات المقيمين في المستشفى.
- جلب بيانات المقيم من رقم الهوية وربطها بملف المريض أو السجل المدني.
- تثبيت العنوان الحالي على: مركز الوفاء لرعاية المسنين والمسنات.
- إضافة البلدة الأصلية، نوع السكن، تاريخ الدخول، الحالة الاجتماعية، تفاصيل الحالة الصحية.
- إضافة خيار يتلقى مساعدة مع حقول نوع المساعدة وتفاصيلها عند التفعيل.
- إضافة قائمة Checkboxes لأنواع الإعاقة: ذهنية، حركية، سمعية، نفسية، بصرية، كلية مع حقل إعاقة استثنائية.
- إضافة خيار الوفاة مع تاريخ الخروج/الوفاة.
- إضافة الوضع الوظيفي، وإظهار نوع العمل فقط عند اختيار يعمل.
- إضافة قوائم مرقمة للأدوية والأدوات المساعدة؛ Enter ينقل للبند التالي تلقائياً.
- إضافة خانة الأمانات عند الدخول.
- إضافة قائمة شاملة لكل المسنين والمسنات مع خروج نهائي وزيارة مؤقتة من/إلى.
- إضافة إحصائيات تفصيلية وتصدير Excel.
- إضافة حساب مسؤول القسم:
  elderly.care / Elderly@2026
- الحفاظ على حلول v4.3.80 الخاصة بمنع الشاشة البيضاء أثناء إنشاء التقارير.
