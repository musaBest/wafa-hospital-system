Wafa Hospital System v4.3.18
============================

1) إصلاح حفظ المستخدمين والصلاحيات نهائياً
- تعديل المستخدم من شاشة المستخدمين والصلاحيات أصبح يكتب الصلاحيات مباشرة إلى user_permissions داخل نفس transaction.
- يتم تفعيل permissions_customized وحفظه فعلياً في قاعدة البيانات.
- بعد الضغط على حفظ، الواجهة تعيد قراءة المستخدم من قاعدة البيانات قبل إغلاق نافذة التعديل للتأكد من ثبات التغيير.
- الصلاحيات المالية المخفية تبقى محفوظة عند تعديل المستخدم من حساب المهندس أحمد، ولا يمكنه إضافة صلاحيات مالية جديدة.
- تم تعديل DatabaseSeeder حتى لا يعيد كتابة بيانات/دور/كلمة مرور/صلاحيات المستخدمين الموجودين عند تشغيل db:seed مرة أخرى.
- Migration إصلاحي يربط أي صلاحيات مخصصة قديمة بالحسابات التي تحتوي user_permissions بالفعل.

2) المختبر والأشعة — دليل خدمات مرن ومتكامل
- إضافة إدارة مركزية لأنواع الفحوصات المخبرية وأنواع الأشعة.
- إضافة نوع فحص جديد أو نوع أشعة جديد.
- تعديل الاسم العربي والإنجليزي والفئة.
- تعديل السعر لمن لديه صلاحية أسعار الفحوصات.
- حذف/أرشفة نوع فحص أو أشعة.
- المختبر: إضافة/تعديل/حذف بنود التحليل الافتراضية مع Reference Range لكل بند.
- شاشة المختبر تحتوي تبويب إدارة الفحوصات والأسعار.
- شاشة التشخيص والأشعة تحتوي تبويب دليل شامل مع فلترة للكل/المختبر/الأشعة وبحث.
- طلب الأشعة أصبح قابلاً لتحديث الحالة وكتابة تقرير/نتيجة الأشعة.
- دليل الفحوصات أصبح متصلاً بقاعدة بيانات Laravel عبر API، لذلك التعديلات تظهر للمستخدمين الآخرين وليست محلية في المتصفح فقط.

3) صلاحيات جديدة للمختبر ودليل الفحوصات
- diagnostic_catalog.view
- diagnostic_catalog.create
- diagnostic_catalog.update
- diagnostic_catalog.delete
- diagnostic_catalog.manage (تعديل الأسعار)

مهم بعد التحديث
---------------
نفّذ:
php artisan migrate
php artisan db:seed
php artisan config:clear
php artisan cache:clear

ثم npm install / npm run dev للواجهة.

تحسينات ثبات إضافية في النسخة النهائية
--------------------------------------
- حتى حساب cashier المدمج، إذا تم تخصيص صلاحياته من شاشة المستخدمين، تصبح الصلاحيات المحفوظة هي المصدر الفعلي بعد Refresh.
- تشغيل db:seed لا يعيد أسعار/أسماء/بنود دليل المختبر والأشعة إلى القيم الافتراضية، ولا يعيد خدمة سبق حذفها.
- مسار إصلاح تسجيل الدخول للحسابات الافتراضية لا يلغي بعد الآن كلمة مرور أو حالة أو دور أو صلاحيات سبق تعديلها من شاشة المستخدمين.
