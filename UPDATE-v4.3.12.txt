Wafa Hospital System v4.3.12
===========================

المرحلة الأولى من إعادة بناء قسم المبيت: القسم الإداري.

الجديد:
- واجهة إدارية مستقلة وحديثة لقسم المبيت، بدون خلط مع الملف المالي.
- لوحة مؤشرات للحالات الحالية، الرجال، النساء، والتخريج اليومي.
- عروض منفصلة: الموجودون حالياً، الخارجون حديثاً، وكل الحالات.
- تسجيل حالة مبيت جديدة يبدأ برقم الهوية وجلب الاسم الرباعي والجنس وتاريخ الميلاد من API السجل المدني.
- الحالة الاجتماعية والعنوان حقول إدارية يعبئها المستخدم يدوياً.
- تشخيص الحالة داخل نموذج التسجيل.
- نوع قسم المبيت: رجال / نساء مع منع عدم التوافق مع جنس المريض.
- جهة التغطية: قائمة اختيار بعلامة checkbox مع إمكانية إضافة جهة جديدة فوراً.
- المشفى المحوِّل: قائمة اختيار بعلامة checkbox مع إمكانية إضافة مشفى/جهة جديدة فوراً.
- حقل الطبيب المحوِّل، الغرفة، السرير، تاريخ ووقت الدخول والخروج المتوقع.
- عرض ملف إداري مختصر لكل حالة وإمكانية التخريج الإداري.
- طلبات التحويل القديمة للمبيت بقيت قابلة للقبول من نفس الوحدة الجديدة.
- تم إيقاف أي احتساب مالي تلقائي عند إنشاء الحالة الإدارية الجديدة (dailyRate=0 / contributionPct=0). الملف المالي سيبنى في المرحلة التالية.
- أضيفت حقول قاعدة بيانات خاصة بالملف الإداري للمبيت: ward_type, marital_status, address, referral_hospital, referring_doctor.
- مستخدم لديه admissions.create يستطيع استخدام lookup السجل المدني اللازم لتسجيل حالة المبيت.

بعد فك الضغط شغّل migrate لأن هذه النسخة تحتوي migration جديد.
